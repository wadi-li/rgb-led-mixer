# Эмулятор смешения цветов RGB-светодиода

[Открыть эмулятор](https://wadi-li.github.io/rgb-led-mixer/)

Автономный инструмент для ручного смешения света трёх каналов с учётом длин волн из даташита.

- Длины волн каждого канала: 380–780 нм.
- Три движка интенсивности: 0–100%.
- Поле свечения и сплошная цветовая заливка.
- Чёрная тема по умолчанию и переключатель светлой/тёмной темы.
- Поправки относительной оптической мощности или светового потока каналов.
- Координаты CIE x, y и экранный HEX.
- Сохранение настроек в браузере и скачивание автономного HTML.

## Использование

Введите пиковые длины волн λpeak каналов R/G/B и перемещайте движки. При наличии данных о мощности раскройте «Поправки мощности и модель расчёта» и задайте относительные величины в одинаковых единицах. Можно также скачать index.html и открыть его локально без установки.

## Модель и ограничения

Источники считаются монохроматическими; интенсивность линейно соответствует относительной оптической мощности. Цветовые функции CIE 1931 вычисляются по [приближению Wyman, Sloan & Shirley (2013)](https://jcgt.org/published/0002/02/01/). Суммирование выполняется в XYZ, затем результат преобразуется в sRGB с отсечением отрицательных компонент.

Длина волны λd вместо λpeak, ширина спектра, реальная мощность каналов и цветовой охват монитора ограничивают точность. Абсолютная яркость и эффект свечения условны. Эмулятор не заменяет колориметр.
